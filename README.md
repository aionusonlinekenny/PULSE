# PULSE · System Monitor

Theo dõi CPU, GPU, RAM, ổ cứng và mạng theo thời gian thực trên Windows.

Repo này chỉ chứa các bản phát hành của PULSE (dùng cho việc tải về và tự cập nhật).

## Tải về

Tải `PULSE.exe` ở mục [Releases](https://github.com/aionusonlinekenny/PULSE/releases/latest) rồi chạy. App cần quyền quản trị (để đo FPS và kết thúc tiến trình hệ thống). Các bản sau app sẽ tự cập nhật.

Yêu cầu Windows 10/11 có WebView2 Runtime.
